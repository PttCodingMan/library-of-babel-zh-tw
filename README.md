# 巴別圖書館・繁體中文館

波赫士〈巴別圖書館〉（1941）與 Jonathan Basile 的 [libraryofbabel.info](https://libraryofbabel.info) 的繁體中文版。

用這些字寫成、長度在 3,200 字以內的每一段文字，都已經在館裡的某一頁。

## 館內

- **翻閱**：隨機抽一頁，或輸入位址前往；左欄用六角形平面圖與書架格標出目前的牆、架、冊、頁。網址列就是目前的位置：`#a/<室號>/<牆>/<架>/<冊>/<頁>`，複製下來即可分享。
- **尋找**：輸入一段文字，算出它所在的那一頁。
- **你的一生**：輸入某一天說過（或將要說）的一句話、發生的一件事，找到早已寫著它的那一頁；可收進只存在自己瀏覽器裡的索引。
- **關於**：原典與原理。

## 規格

| 項目 | 數值 |
|---|---|
| 字集 | Big5（cp950）全部 13,060 個漢字 ＋ 全形空白 ＋ 19 個全形標點，共 13,081 字 |
| 每頁字數 | 3,200 |
| 位址 | 室號（36 進位）＋ 4 牆 × 5 架 × 32 冊 × 410 頁 |
| 總頁數 | 13,081³²⁰⁰ ≈ 10¹³¹⁷³ |

標點：`，。、；：？！「」『』（）《》〈〉—…·`。簡體字、英文字母與數字不在字集內；搜尋時半形標點與空白會自動轉成全形。

## 原理

館裡什麼都沒有存。

1. 一頁 3,200 字看成一個 13,081 進位、3,200 位數的整數 `C`（字元在字集中的序號即位數）。
2. 位址 `A = f(C)`，`f` 是 `[0, 13081³²⁰⁰)` 上一個固定的雙射，**分層置亂**：一頁的長度 `n` 是最後一個非空白字的位置，長度為 `n` 的頁面恰好是 `[N^(n-1), N^n)` 這一段（全空白頁是 0），`f` 只在段內置換。段內做法：在 `2^k`（k 為該段大小的位元數）上交替「乘以奇數常數 mod 2^k」與「`x ^ (x >> ⌈k/2⌉)`」，再用 cycle walking 限制回段內。因此內容越短，位址越小：18 字的句子室號約 45 碼，寫滿的頁約 8,461 碼。
3. `A = 室號 × 262,400 + ((牆·5 + 架)·32 + 冊)·410 + 頁`。

因為 `f` 可逆，每一頁恰好出現一次；搜尋就是算 `f(C)`，翻閱就是算 `f⁻¹(A)`。所有大數運算都用瀏覽器原生的 `BigInt`，各段的常數由固定種子（加上段的位元數）的 PRNG 產生，所以每個訪客看到的是同一座圖書館。

## 檔案

```
index.html         單檔網頁，直接用瀏覽器開啟即可
DESIGN.md          介面的設計 brief（Visual DNA、色票、神祕元素的界線）
src/core.js        字集、位址換算、置亂函數
src/template.html  介面
src/hanzi.txt      Big5 漢字表（由 build.py 產生）
build.py           產生 hanzi.txt 並組出 index.html
test.js            Node 測試：隨機頁面來回換算、搜尋還原
```

修改 `src/` 後執行：

```sh
python3 build.py
node test.js
```

> 注意：改動 `src/core.js` 裡的字集順序、種子或置亂函數，會讓所有既有位址失效。
