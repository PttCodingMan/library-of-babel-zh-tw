# 巴別圖書館・繁體中文館

**推門進去 → [codingman.cc/library-of-babel-zh-tw](https://codingman.cc/library-of-babel-zh-tw/)**

館裡有大約 10¹⁶⁴⁶ 頁書。每一頁都是一張四百字的稿紙，二十行，每行二十格，用一萬三千零八十一個字寫成：Big5 裡的每一個漢字、一格全形空白，和十九個標點。

凡是四百字以內、用這些字寫得出來的文字，都已經在其中某一頁。沒有人寫過它們，它們也從來不需要人寫。

你小時候那篇〈我的志願〉的第一段在這裡，一字不差；被老師用紅筆圈出錯字的那個版本，也在。你昨晚想說、終究沒說出口的那句話在這裡。你寫給某人的最後一句話在這裡，對方沒有回的那一句也在。李白沒來得及寫的那首絕句在這裡，緊挨著它的，是只差一個字、就不再是好詩的那一首。

絕大多數的書頁是讀不懂的亂碼。而正因為什麼都有，沒有哪一頁能替自己擔保：寫著真話的那一頁旁邊，永遠排著數不清的、措辭一樣工整的謊言。

館裡其實什麼都沒有存。每一頁都是在你翻開的那一刻，才在你的瀏覽器裡被算出來的。網址裡沒有文字，只有座標：哪一間六角形閱覽室、哪一面牆、第幾層架、第幾冊、第幾頁。每個座標都一樣長，因為在這座館裡，找到一頁需要的，和寫出一頁一樣多。

這是波赫士〈巴別圖書館〉（1941）與 Jonathan Basile 的 [libraryofbabel.info](https://libraryofbabel.info) 的繁體中文版。

## 館內

- **翻閱**：每一頁是一張直排的四百字稿紙（可切換橫排）。隨機抽一頁，或輸入位址前往；左欄用六角形平面圖與書架格標出目前的牆、架、冊、頁。鍵盤 ← → 翻頁、R 隨機一頁。網址列就是目前的位置：`#d/<室號>/<牆>/<架>/<冊>/<頁>`，室號是 64 進位、固定 909 碼、冊與頁補零，所以不論那頁寫了多少字，網址都一樣長；複製下來即可分享。
- **尋找**：輸入一段文字，旁邊的稿紙與位置會隨著每打一個字即時更新，就是它此刻所在的那一頁。
- **你的一生**：輸入某一天說過（或將要說）的一句話、發生的一件事，找到早已寫著它的那一頁；可收進只存在自己瀏覽器裡的索引。
- **關於**：原典與原理。

## 規格

| 項目 | 數值 |
|---|---|
| 字集 | Big5（cp950）全部 13,060 個漢字 ＋ 全形空白 ＋ 19 個全形標點，共 13,081 字 |
| 每頁字數 | 400（一張 20 × 20 的四百字稿紙） |
| 位址 | 室號（64 進位，固定 909 碼）＋ 4 牆 × 5 架 × 32 冊 × 410 頁 |
| 總頁數 | 13,081⁴⁰⁰ ≈ 10¹⁶⁴⁶ |

標點：`，。、；：？！「」『』（）《》〈〉—…·`。簡體字、英文字母與數字不在字集內；搜尋時半形標點與空白會自動轉成全形。

## 原理

館裡什麼都沒有存。

1. 一頁 400 字看成一個 13,081 進位、400 位數的整數 `C`（字元在字集中的序號即位數）。
2. 位址 `A = f(C)`，`f` 是整個 `[0, 13081⁴⁰⁰)` 上一個固定的雙射：在 `2^K`（K 為總頁數的位元數）上交替「乘以奇數常數 mod 2^K」與「`x ^ (x >> ⌈K/2⌉)`」，再用 cycle walking 限制回範圍內。不分內容長短一起打散，所以從位址看不出那頁寫了多少字。
3. `A = 室號 × 262,400 + ((牆·5 + 架)·32 + 冊)·410 + 頁`。室號以 64 進位寫成固定 909 碼（數字依序為 `0-9A-Za-z-_`，分大小寫，前面補零），每個網址都一樣長。

因為 `f` 可逆，每一頁恰好出現一次；搜尋就是算 `f(C)`，翻閱就是算 `f⁻¹(A)`。所有大數運算都用瀏覽器原生的 `BigInt`，置亂常數由固定種子的 PRNG 產生，所以每個訪客看到的是同一座圖書館。

## 檔案

```
index.html         單檔網頁，直接用瀏覽器開啟即可
og.jpg             分享連結時的預覽圖
DESIGN.md          介面的設計 brief（Visual DNA、色票、神祕元素的界線）
src/core.js        字集、位址換算、置亂函數
src/template.html  介面
src/hanzi.txt      Big5 漢字表（由 build.py 產生）
build.py           產生 hanzi.txt 並組出 index.html
test.js            Node 測試：隨機頁面來回換算、搜尋還原
```

修改 `src/` 後執行：

```sh
python3 build.py
node test.js
```

> 注意：改動 `src/core.js` 裡的字集順序、種子或置亂函數，會讓所有既有位址失效。
